# compony-project

Modern, Full-Stack Luxury Streetwear E-Commerce Platform.

## 🚀 Features
- **Frontend**: React 19, Vite, Framer Motion, Redux Toolkit, Lucide Icons
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT Authentication
- **Dual-Theme**: High-end Luxury Minimalist Light Mode & Midnight Dark Mode
- **Interactive UI**:
  - Live Multi-Currency Switcher (USD, INR, EUR, GBP)
  - Quick-Size Pills & 1-Click Bag Add
  - Interactive Size Guide & AI Fit Calculator
  - 2.2x High-Definition Garment Magnifier Lens
  - Interactive Cart Drawer with Dynamic Coupons & Free Shipping Progress Bar
  - Glassmorphism Toast Alerts
  - Circular Back-to-Top Progress Indicator

## 📦 Getting Started

### 1. Backend Setup
```bash
cd server
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev
```
